SIP Laboratorium Fikomm UMBY
Aplikasi berbasis web (Single-Page Application) untuk mengelola inventaris peralatan laboratorium, fasilitas ruangan studio, serta pengajuan peminjaman secara real-time bagi mahasiswa dan petugas Fakultas Ilmu Komunikasi dan Multimedia (Fikomm) Universitas Mercu Buana Yogyakarta (UMBY).
